# 박물관나우 (kr-museum-now)

**내 주변 박물관·미술관을 지도에서 찾고, 오늘 여는 곳만 골라 본다.** 국내 사용자 대상, 한국어 UI.

월요일 휴관이 많아 헛걸음이 잦은 니치를 정면으로 판다. 각 기관이 등록한 **휴관일 자연어**를
해석해 "오늘 개관 / 오늘 휴관 / 판정 불가" 세 상태로 지도에 색으로 표시한다. 판정 불가를 개관인
척 숨기지 않고 원문과 함께 정직하게 드러내는 것이 이 앱의 원칙이다.

## 데이터

한국관광공사 국문 **KorService2**(문화시설, `contentTypeId=14`).

- 목록 `areaBasedList2`(1콜) + 상세 `detailIntro2`(관람시간·휴관일·입장료·주차).
- **★ 분류는 cat3 가 아니라 `lclsSystm3` 로 한다.** cat3 는 절반이 빈값이라 **국립중앙박물관조차
  탈락**시킨다(초기 버전의 치명적 누락 — 1,051곳/62%를 놓쳤다). lclsSystm3 은 전건에 채워져 있다:
  - `VE070100` 박물관 (590) · `VE070300` 전시관 (517) · `VE070600` 미술관/화랑 (359)
  - `VE070200` 기념관/문학관 (154) · `VE070500` 과학관/천문대 (60) → **합 ≈1,680곳**
  - 제외(비박물관): 공연장·도서관·문화원·책방·컨벤션·극장 등. 오탐률 ≈0.06%(전수 확인).
- 좌표(WGS84) 채움률 100%. **시도는 areacode 우선, 빈값이면 `addr1` 앞 토큰으로 대체**(cat3 빈값
  박물관은 areacode 도 빈값이라 지역 필터에서 빠지는 함정 — addr1 폴백으로 전건 분류).

## 핵심 기능

- **지도 첫 화면.** 현재 위치 주변부터(권한 거부·미지원·불가를 각각 다른 상태로, 무한 로딩 금지, 서울 폴백).
- **"오늘 여는 곳" 필터(킬러).** 휴관일 원문 → `lib/restday.ts` 의 3상태 파서로 판정. 필터를 켜면
  제외된 "오늘 휴관 N곳 / 판정 불가 N곳"을 화면에 밝힌다.
- **종류·지역 필터**, 지도 이동 시 그 영역 표시(bounds), **⌘K 팔레트**(이름 검색 + 필터, 사이드바와 상태 공유),
  **ESC 레이어링**(검색어 → 팔레트 → 상세).
- 상세 시트: 관람시간·입장료·주차·전화 + **휴관일 원문 항상 표시** + 공휴일 판정 미지원 고지.

## 아키텍처 / 캐싱

- **서버 공간 필터.** 전량(~629)을 통째로 내리지 않고 서버가 캐시된 카탈로그에서 조건에 맞는 가까운
  곳만 골라 준다(`app/api/museums`). 위치·영역이 바뀌어도 상류 호출은 0.
- **★ 목록과 상세를 결합 해제한다.** `areaBasedList2`(목록: 이름·좌표)와 `detailIntro2`(상세:
  휴관일)는 별개 오퍼레이션이고 쿼터도 따로다. **상세가 쿼터 소진돼도 목록·지도·이름은 200 으로
  나간다.** 상세 병합률(`introCoverage`)을 응답 메타에 실어, 병합률이 낮으면 UI가 "오늘 여는 곳"
  필터를 비활성화하고 사유를 고지한다(조용히 전부 `확인 필요`로 두고 0건을 뱉지 않는다).
- **카탈로그 캐시(쿼터 방어의 핵심, `lib/museum-cache.ts`).**
  - `detailIntro2` 는 토큰버킷 throttle(버스트 ~60, 코드 23)이 있어 **pacer(≈12.5 req/s) + 재시도**로
    조여야 통과한다(629건 ≈ 50s, maxDuration 60s 내). — `lib/museum-api.ts`
  - **★ 상세는 정적 스냅샷이 기본이다(`data/intros.json`).** 1,680곳 상세는 (a) 쿼터 1,000/일,
    (b) throttle 로 55s당 ~680건 한계라 런타임으로는 하루에 다 못 받고, 인스턴스 메모리는 인스턴스가
    바뀌면 0% 로 돌아간다. 그래서 `npm run collect:intros`(`scripts/collect-intros.ts`, 재개 가능·code 22
    에서 저장 후 중단·실행당 ≤800)가 **오프라인에서 전량을 모아 리포에 커밋**하고, GitHub Actions
    (`.github/workflows/collect-intros.yml`, 매주 월·화 KST 03:00, `--force` 로 가장 오래된 것부터 갱신)이
    이를 자동 갱신한다. 런타임 회전(rotation)은 **정적본에 없는 신규 id 만** 일일 ≤150건 채우고, 그 결과가
    정적본 위에 덮어써진다(`lib/intro-static.ts`, 순수 함수·테스트). `introCoverage` 는 둘의 합산.
  - **완전 빌드**(전량 커버)만 `/api/catalog` self-fetch(`next:{revalidate}`)로 자정까지 공유 Data
    Cache(200). **부분 빌드(회전 중)** 는 목록을 그대로 내보내되 짧게(12분)만 캐시하고 공유 캐시엔 안
    태운다(`/api/catalog` 503 → Next 는 비-2xx 를 담지 않음) → 다음 빌드가 회전을 이어간다.
  - 미수집분은 `openToday=unknown`, UI가 병합률(`introCoverage`)이 낮으면 "오늘 여는 곳" 필터를
    비활성화하고 사유 고지. 쿼터 소진(code 22) 감지 시 배치 조기 중단. **KST 자정 컷**.
  - 한계: `introStore` 는 인스턴스 메모리라 콜드 인스턴스는 누적을 다시 시작(일일 상한이 쿼터를 방어).
    다중 인스턴스 동시 빌드 시 합산이 상한을 넘을 수 있으나, 공유 Data Cache 로 대부분 인스턴스는 읽기만 한다.
- 예열 크론 `/api/warm`(KST 자정 직후) 이 첫 사용자의 콜드 수집을 대신 밟는다.

## 정직성 규칙

- 0건 · 결측 · 실패 · 위치 거부를 화면에서 각각 다르게 표시한다.
- 좌표 없는 항목은 지도에서 빼되 개수를 밝힌다.
- 휴관일 판정 불가(unknown)를 초록(개관)처럼 보이지 않게 회색으로 구분하고 원문을 함께 보여준다.
- **공휴일 휴관은 자동 반영하지 않는다**(캘린더 없음). 한계를 화면에 고지한다.

## 축 2 — 지금 하는 전시 (B553457)

한국문화정보원 "한눈에보는문화정보"(공연전시) API. 신청·승인 완료(2026-09-02).

- 게이트웨이 `apis.data.go.kr/B553457/cultureinfo/period2` · **XML** · 페이지크기 `numOfrows`(소문자 r).
- **realmName=전시** 만 사용(공연·음악·뮤지컬 제외). **좌표(gpsX/gpsY) ~94~98% 보유 → 박물관과 조인 불필요.**
  좌표 없는 소수는 목록 전용(개수 고지, 억지 좌표 금지).
- from/to 는 교차(intersect) 의미. from==to 는 '오늘 시작'만 잡히는 함정이라 안 쓴다. [오늘, 이번달말] 창을
  받아 `start<=day<=end` 로 클라 판정. KST 자정까지 캐시(하루 1~2콜).
- UI: **"지금 하는 전시" 오버레이 토글**(보라 핀) + 시간축(오늘/이번 주말/이번 달). 박물관 레이어와 공존,
  범례 추가. 박물관 축과 **독립**이라 전시 축이 실패해도 박물관 지도는 멀쩡.

## 한계

- 휴관일 자동 판정은 원문 자연어 기반이라 100% 정확하지 않다. 공휴일·임시휴관은 원문·각 기관 공지로 확인해야 한다.
- 박물관 상세(휴관일 등)는 회전 수집이라 배포 후 며칠에 걸쳐 커버율이 100%로 오른다(그 전엔 일부 '확인 필요').
- 전시는 관람시간·입장료 정보가 없다(공연전시 API 스키마에 없음) — 제목·기간·장소·좌표만.
